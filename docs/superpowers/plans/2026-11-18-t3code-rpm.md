# T3 Code RPM Implementation Plan

**Goal**
Ship T3 Code's native desktop app for Fedora 45 x86_64 with automated stable-release tracking and signed COPR distribution.

**Architecture**
Resolve stable GitHub releases and serialize publishing jobs. Compile the Linux unpacked application in a Fedora container and package it in a source-buildable RPM spec. Keep GitHub publication staged until the COPR build and repository checks pass.

**Tech stack**
Bash, Python, RPM, Fedora containers, GitHub Actions, and Fedora COPR.

**Spec**
See [architecture](../../architecture.md) for the packaging and publication design.

## Global constraints

Build Fedora 45 x86_64 RPMs named `t3code`. Preserve Chromium sandboxing, pin upstream source and verify toolchain inputs, keep publication credentials away from upstream build code, and never replace an already published NEVRA.

## Review focus

Test stable release filtering, malformed manual input, interrupted release attempts, forced revision allocation, and COPR build reuse. Perform a clean DNF install, graphical startup, RPM verification and removal in Fedora.

## Tasks

- [x] Implement release selection and persistent revision allocation in `scripts/check-upstream.py`. Run the release detection unit tests and resolve the current stable tag against GitHub.
- [x] Implement the native build and RPM spec in `scripts/build.sh`, `scripts/package.sh`, and `packaging/`. Build the stable tag into an installable RPM and a rebuildable SRPM.
- [x] Implement package verification in `scripts/test-package.sh`. Confirm installed files, dependencies, application version, sandboxed graphical startup, and package removal.
- [x] Implement serialized CI and COPR reconciliation in `.github/workflows/` and `scripts/publish-copr.sh`. Verify remote chroot support and run static workflow checks. Verify the actual build and repository when configured.
- [x] Document initial configuration, builds, retries, and installation in the README and `docs/`.
